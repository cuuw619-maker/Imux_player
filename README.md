# Imux Player

Local-first Android music player built with Kotlin, Jetpack Compose, Material 3 and Media3.

## Foundation
- Kotlin + Jetpack Compose
- Material 3
- Room library index
- DataStore settings
- Storage Access Framework folder permissions
- Centralized audio-format registry
- Recursive background library scanning
- Media3 ExoPlayer + MediaSession background playback
- GitHub Actions lint, unit tests and debug APK build

The project is intentionally structured for incremental expansion into playlists, queue management, search, artwork, audio effects and adaptive player surfaces.
